# VIP Finance — Sleek design direction

Redesign VIP Finance from the ground up as a premium mobile-first personal finance product. Preserve all current functionality and stored data; change the visual system completely.

FUNCTIONAL SCOPE: dashboard, operations, income/expense/transfer, accounts/cards, category icon/color customization, budgets, analytics, converter, debts, goals, reminders, receipt OCR, local smart signals, settings, themes and JSON backup/export.

VISUAL DIRECTION: luxury minimalism. Think private-banking / premium fintech: near-black graphite, ivory, restrained platinum and warm gold accents. Use fewer visual elements, stronger typography, generous whitespace, crisp alignment, subtle borders, low-noise surfaces and precise hierarchy. Avoid excessive gradients, playful decoration and clutter.

HOME: make the current balance the dominant visual anchor. Secondary metrics become compact, high-information modules. Operations should read like a refined ledger. Accounts should feel like premium financial instruments. Analytics should prioritize clean charts and concise insights.

COMPONENTS: use tighter corner radii, restrained elevation, high-quality typography, compact chips, elegant segmented controls, polished bottom actions and intentionally designed dialogs. Every interaction should look expensive and deliberate.

ANDROID: Kotlin + Jetpack Compose + Material 3 foundations, but with a distinctive luxury-fintech identity. Preserve business logic, navigation, persistence and compatibility. Redesign every screen and dialog, not just the home screen.
